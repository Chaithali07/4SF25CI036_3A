Restaurant Data Analysis – Milestone 1
In this project, I worked on analysing a restaurant dataset using Python and its libraries like Pandas, NumPy, Matplotlib and Seaborn. The main aim of this project was to understand the dataset, clean and transform the data, handle missing values and find useful insights from it. I started by reading and exploring the dataset, checking its data types, identifying and removing duplicate values, and performing the required data transformations. I also created a new feature called "cuisine_count" and handled missing values using mean imputation wherever applicable.
After completing the data cleaning and preprocessing, I performed different analyses to understand the restaurant data better. This included finding the top 10 highest-rated restaurants, identifying the most popular cuisines, finding the most reviewed restaurants, calculating the average restaurant cost and comparing average ratings across different cuisines. I also created visualisations to represent these findings, along with restaurant cost and rating distributions, using Matplotlib and Seaborn. Overall, this milestone helped me understand how to work with a real-world dataset, perform data analysis using Python and present the results through meaningful visualisations. The project files include the Jupyter Notebook ("Assignment1.ipynb"), the original dataset ("resta_data.csv") and the project documentation ("README.md").
